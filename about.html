关于 theo

学生，一个普通但认真的网友。喜欢动漫、日式音乐，也喜欢把想明白的东西写下来。

开这个站的原因很简单：记录散落在各种 App 里的东西——笔记、看过的番、循环的歌——最后都不如写在一个能被看到的地方。如果你也喜欢其中某一样，那我们大概能聊得来。

能力条

自己估的，不是考出来的分数。

这个站是怎么做的

  • 纯静态：HTML + CSS + 原生 JS，没有框架、没有后端
  • 背景是设置的那张动漫截图，带缓慢缩放的呼吸感
  • 上层飘着 Canvas 光尘，偶尔划过一颗彗星
  • 打卡和投稿数据用 localStorage 存在本地，可导出 JSON
  • 字体用霞鹜文楷，通过 CDN 加载
  • 右上角可以切到「星夜」模式

想聊点什么

发现番单/歌单品味重合、想交流学习方法，或者只是想打个招呼，都可以去学习模块的投稿区留言。
